## Start Here: A simple formula for good prompts
Use this easy pattern:

Context + Task + Output style + Boundaries

You can remember it as: "What this is, what I need, how I want it, what to avoid."

Quick template:
- "This is [context]."
- "Please [task]."
- "Give it to me as [format/style]."
- "Use only [source/limit] and avoid [anything sensitive/off-topic]."

Example:
"This is a meeting thread about Q4 budget approvals. Please draft a reply confirming next steps. Keep it under 120 words, friendly and professional. Use only details from this thread."

## Outlook: Example prompts you can use today

### Example 1: Catch up after being away
"Summarise my unread emails from the last 2 days. Group them into: urgent, waiting-for-me, and FYI. For urgent ones, suggest a one-line reply I can send."

### Example 2: Draft a clear reply
"Draft a polite reply to this email. Confirm we received the request, ask for the missing purchase order number, and suggest a call tomorrow afternoon. Keep it concise and professional."

### Example 3: Prep for a meeting
"Look at my recent emails about Supplier Renewal and list key decisions, open questions, and deadlines in a short bullet list."

## Word: Example prompts you can use today

### Example 1: Turn notes into a polished update
"Using the text in this document, create a one-page project update with these headings: Progress, Risks, Next Steps, and Owners. Keep the tone plain and business-friendly."

### Example 2: Make a draft easier to read
"Rewrite this draft in plain English for a mixed audience. Shorten long sentences, remove jargon, and keep the meaning the same."

### Example 3: Build a first draft from rough points
"Create a first draft client update from the bullet points below. Keep it warm and professional, around 250 words, and end with 3 clear action points."

---

## Excel: Example prompts you can use today

### Example 1: Explain what changed
"Look at this table and summarise the 5 biggest cost changes from last month to this month. Use plain language and present it as a simple bullet list."

### Example 2: Spot unusual values quickly
"Find amounts that look unusual in this expense report and show them in a small table with: where it appears, amount, and why it stands out."

### Example 3: Create a manager-friendly summary
"Create a short summary of this sheet for a non-finance manager: total spend, biggest cost areas, and any trend that needs attention this month."

## If Copilot gives a weak answer, improve your prompt with one extra line
Try adding one of these:
- "Use only information from this document/email thread/sheet."
- "Ask me up to 2 clarifying questions if information is missing."
- "Give me the output as 5 bullets, then a short action list."
- "Keep the tone friendly and clear for non-specialists."

## Data-safety habit (from Day 1): keep client data in approved tools
Copilot for Microsoft 365 is designed for your organisation's approved work environment. Keep using the Day 1 habit:
- Work with client and internal business data only in approved company tools.
- Do not paste confidential client data into external public AI tools.
- If unsure whether a tool is approved, check with IT before using client data.

This is not about stopping you from using AI. You can use Copilot for normal day-to-day work; this habit is about using client data safely in approved tools.

---

## Final tip
You do not need a "perfect prompt" to start. Write a simple request, see the result, then refine it with one extra detail. Small improvements usually give much better answers.
